# Description WIP
# There are two boards which are a part of this project. One is the actual RP2354A Minima board, and the other is the GPIO expansion board. For each board, the PDF is the schematic, and the Gerber files can be opened in most Gerber viewers to see the fabrication outputs for the board. To help recognize whether the Gerber files processed properly in the viewer, one should know that the RP2354A Minima is a 4-layer PCB and the GPIO expansion is a 2-layer PCB.
